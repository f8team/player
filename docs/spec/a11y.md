# Accessibility (WCAG 2.1 AA)

## Non-negotiable rules

1. Every interactive control is a real `<button>` (or `<input type="range">` for the seek bar) with a meaningful `aria-label`.
2. Focus is always visible. Theme tokens expose `--reel-focus-ring` so consumers can override; the default is a 2 px solid ring with 3:1 contrast against the background.
3. The player container is keyboard-focusable. When focused, Space toggles play/pause and Arrow keys seek. The `keyboard.scope = "container"` option scopes hotkeys so they only fire when the player has focus.
4. Live region (`aria-live="polite"`) announces state changes invisible to sighted users: quality auto-switch, subtitle on/off, error recovery.
5. Fullscreen traps Tab focus inside the player container; Escape restores focus to the trigger.
6. Captions menu, quality menu, and playback rate menu are reachable by keyboard, navigable with arrow keys, and dismissible with Escape.
7. Color contrast for text (time, labels) is ≥4.5:1 against the chrome background; for UI chrome (buttons, icons), ≥3:1.

## ARIA mapping

| Control              | Role                                     | Key attributes                                                                                            |
| -------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Container            | `region`                                 | `aria-label="Video player"` (configurable)                                                                |
| Play/Pause           | `button`                                 | `aria-label`, `aria-pressed={playing}`                                                                    |
| Seek bar             | slider via native `<input type="range">` | `aria-label="Seek"`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, `aria-valuetext="MM:SS of MM:SS"` |
| Volume               | slider                                   | `aria-label="Volume"`, `aria-valuenow={0..100}`                                                           |
| Mute toggle          | `button`                                 | `aria-pressed={muted}`, `aria-label="Mute" / "Unmute"`                                                    |
| Captions toggle      | `button`                                 | `aria-pressed={captionsOn}`                                                                               |
| Quality menu trigger | `button`                                 | `aria-haspopup="menu"`, `aria-expanded`                                                                   |
| Quality menu         | `menu`                                   | each item is `menuitemradio` with `aria-checked`                                                          |
| Playback rate menu   | `menu`                                   | each item is `menuitemradio`                                                                              |
| Fullscreen toggle    | `button`                                 | `aria-pressed={fullscreen}`                                                                               |
| PIP toggle           | `button`                                 | `aria-pressed={pip}`                                                                                      |

## Captions

- The native `<track>` elements are mounted and the browser CC menu remains
  available as a fallback even if the consumer hides the player's own captions
  menu.
- The captions menu mirrors the active `<track>` and dispatches
  `subtitles:change` on selection.

## Testing

- Storybook + `@storybook/addon-a11y` (axe-core) runs on every story; CI fails on any new violation.
- Playwright E2E runs `axe-playwright` on each surface (classroom, story, admin).
- Manual screen-reader pass on NVDA + Chrome and VoiceOver + Safari before each major release.
